1 LINE公式アカウントの作成

まだLINE公式アカウントをお持ちでない場合は、開設ページから作成してください。

Messaging APIを利用するために、LINE Developersへの登録が必要です。

3 設定情報の取得と入力

Channel ID / Channel Secret / Channel Access Token を接続設定に入力します。

Webhook URLをコピーし、LINE Developers Consoleに貼り付けて検証します。

5 応答設定の変更

応答メッセージをオフ、Webhookをオンに設定します。
